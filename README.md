# Fixly

Fixly is a bidding-based marketplace for home maintenance services.

## Project Overview

Fixly connects customers with verified service providers and allows customers to receive and compare multiple bids for their service requests.

## Technology Stack

### Web Application
- React
- Vite

### Mobile Application
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Real-Time Communication
- Socket.IO

### Maps
- Leaflet/OpenStreetMap or Google Maps API

### File Storage
- Cloudinary / S3-compatible storage
